# 教学对照固定输入材料

本目录是原创 fixture，不是真题、真实招生公示或真实个人学习记录。没有模型答案或判分。

- `inputs.json` 含完整 17 个 caseId，结构为 prompt/images/notes；images 是绝对路径。
- 01—06、10—12、17 的 prompt 与仓库 cases.json 原输入逐字一致。
- 07 原创选择题在 D 选项文字中部真实裁切；08 原创数学式尾项模糊，分母 x² 确定，prompt 明示两种可能读法。
- 09 只含首轮请求；宿主需继续追问猜测选项，最后明确交卷并报告实际用时。不得在首轮附带后续轮次。
- 13 两校名称和数字全部虚构，仅匿名聚合；数据缺口不能补成真实招生事实。
- 14 无历史记录分支；15 原创 ReviewQueue 1.2 含到期、未来、证据不足的掌握标记。
- 16 初始3个空页框；按受限工具测试运行，禁止脚本和笔记写入。不是对本机安装状态的描述。
- 新旧插件必须收到同一 prompt 和同一图片；两次模型调用使用同一宿主、模型、推理档位和日期基准。
- `SHA256SUMS.txt` 校验本目录除自身外全部材料；`build_fixtures.py` 为可复现生成脚本。
