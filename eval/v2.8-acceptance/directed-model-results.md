日期：2026-10-18。绑定源码 `6a3bb47d973aaa9c545b65e55262c9f6e9e629a8`、版本 `2.8.0-dev.1`、51 文件树 `f7d13515ad4e6246f9140206880dd21defe4d90bf8f3346730362249dcabb959`。本次固定的 20 个知识点请求经主 Agent 与独立 Agent 逐项复核均通过；另列的 1 个工具定向请求也通过。它们不证明原生插件发现或自动路由通过，没有维护者人工签收，也不推断真实学生的学习效果。

## 采集条件

输入来自 [2.7 知识点验收集](../v2.7-acceptance/cases.json)，`reviewOnly` 留在评分侧。每个案例使用新子 Agent，显式要求读取 tutor 或 error-loop 的候选正文及必要引用；不读取其他安装缓存、评分目录或真实笔记。DS-01 首条预检将问题直接放入控制消息，其余从各自工作区 `request.txt` 读入，用户问题原文保持一致。

宿主为 Codex app 子 Agent 的既有执行环境，审批为 never、权限为继承的 danger-full-access，没有修改失败 CLI 的 sandbox、守卫或审批设置。**这与 CLI workspace-write 试跑是两种环境**；不能称 CLI 已恢复，也不是客户端已安装候选插件的证明。

模型均为 `gpt-6.1-sol`；DS-01 至 CN-01 的 10 条为 xhigh，CN-02 至 LOOP-02 的 10 条为 high。因此只报告逐案例功能结果，不称单一固定档位批次、不计算全局准确率、不作新旧版本效果比较。20 条均有成功返回完整目标 Skill 和依据契约的证据，各工作区运行前后摘要相同。

OS-02、OS-03、CN-01 首次遇额度错误，没有算成有效回答；在所报重置时间之后核对可用状态，沿用同一任务/工作区完成。采集器最初未识别部分嵌套 JSON、相对路径和换行形式，已根据原始返回修正提取；原回答没有改写，修正不是一次新的模型答题。只提取公开 final/commentary 和真实工具调用/返回，不提取隐藏推理。
