# 408 知识点与大纲依据契约

本契约用于 408 单题讲解和跨题错因整理。索引见 [kp-408.json](kp-408.json)，结构约束见 [kp-408.schema.json](kp-408.schema.json)。首批 60 条是项目编辑优先级，不是历年命题频率统计；本版不填教材章节或页码。

## 匹配与证据含义

1. 根据题面、设问和用户实际过程定位相关条目，只读取当前任务需要的条目。`id` 是项目内部标识，不是官方大纲编号。`topicPath` 是项目分类；`syllabusPath` 才是实际核对过的年度大纲路径。不要把两者混用。
2. `aliases` 只用于辅助查找，不代表适用性判断。比如 FIFO 可能指队列顺序，也可能指页面置换，应先看题面是否有页框、引用串和淘汰过程。跨科综合题可以列多个条目；不为凑标签强行匹配。
3. `basisYear` 为实际依据年度或“待核”；`verified` 仅表示与所列年度、所列来源文档的映射已核验，不证明定义、公式、计算、标准答案或个人错因正确。`source.kind` 区分考试主管机构原始发布、学校等官方转载及用户提供原始材料；转载来源写实际发布学校，不能冒称教育考试院或出版社原版。
4. `verified: true` 必须有确定年度、实际读过的来源正文、`syllabusPath`、来源标题/发布者/引用标识/条目定位、文档 SHA-256 及 `checkedAt`。`mappingScope: topic` 表示主题归属已对照，不保证所有别名均逐字列于原文；`upper-topic` 仅表示上位范围，须说明具体细节是项目展开。只有网页标题、摘要、招生目录列出 408 或模型记忆，不能升级为已核。`material:` 引用只用于当前实际提供且可定位的材料，不虚构材料身份。
5. 年度不同于用户指定考试年度时明确写“已核的是某年，目标年度仍待核”，不能沿用旧年已核状态证明新年范围。索引未实际更新前，不在回答中默默把 `false` 改成已核。

当前部分条目仅对照学校公开的 2025 年材料。使用这些条目时写清“2025 年学校公开材料映射已核”；目标为 2027 年时另写“2027 年仍待核”。目标年度未提供时也保留实际 2025 年和转载属性，不省略为“当前大纲已核”。PDF 页码是来源定位，不是教材页码。

## 每题输出

完成解释或讲评时，为每题增加简短的 `【知识点依据】`：项目 ID、知识点/项目分类、依据年度、核验状态；已核时给来源与条目定位。先区分题目来源标注与知识点大纲归属，它们不是同一项核验。

当前条目为待核时，格式示例：

> 【知识点依据】OS-MEM-001｜FIFO 页面置换｜项目分类：内存管理→页面置换｜大纲年度：待核；年度归属未核验。

这是索引条目的项目分类示例，不是官方大纲原文。按题目另说明 FIFO 的规则、适用条件和实际计算复核方式；不能说“大纲已经证明这个答案正确”。

未收录或无法可靠匹配时写“【知识点依据】未收录/待核”，不要编 ID、章节、页码或 URL。未知映射值用 `null`；仅在输出需要结构化映射时如此表达，不新增或改写已有学习记录 Schema。

用户只要提示、正在独立作答或尚未交卷时，若精确知识点、算法名称或依据定位会泄露解法，当前只给宽泛主题并写“详细依据留到讲评”，等允许讲评再补逐题依据。不要为了格式要求提前揭示答案或验证题解法。

## 错题整理与正确性

- 跨题整理时逐题标明映射，再按实际观察聚类；知识点标签不能把原因假设升级为已确认。
- 数学、英语、政治任务不套用 408 索引；混合任务只给其中的 408 条目标注，不影响其他学科规则。
- 公式来源、成立条件与独立复算分别说明。脚本成功输出才能说脚本核验；人工推导照常标明，不因有知识点 ID 就声称工具已验证。
- 所有来源不确定项保持可见，不把“待核”包装成已提供权威依据。索引不能用于宣布本版已覆盖全部 408 知识点。

## 解题规则的独立出处

具体公式或状态更新规则按 [规则依据说明](knowledge-point-basis.md) 与 [规则卡](rule-cards.json) 核对，只读取本题匹配的卡片。规则卡保留项目原创归纳身份；外部引用只支持其明确列出的规则范围，项目初态、排序和片末排队等约定不能凭引用升级为权威规定。外部规则已核不改变本索引的年度大纲映射状态。

完整讲评给出实际规则、关键条件、规则出处及其核验范围，再列年度映射。局部追问只补所问部分；只提示或未交卷时，把会泄题的算法名、精确 ID、公式及定位延后。没有外部出处时明确“项目归纳，外部规则出处待核”，人工复核与实际成功调用的脚本核验分别标注。
