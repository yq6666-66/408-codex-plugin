# 计算实现与题面约定

这些约定描述随包 `scripts/study_simulator.py` 的实际行为，不是所有教材或考试题的统一默认。题目约定冲突时改用人工复核或先澄清，不能用程序默认值替代题意。

## Cache

- `--block-size` 按字节，输入地址按字节地址；本模拟器要求块大小与行数均为正的 2 的幂，初态为空。全相联 LRU 的一般定义不要求缓存行数为 2 的幂。
- 直接映射：块号 = 地址整除块大小；行号 = 块号 mod 行数；标记 = 块号整除行数。
- offset 位数 = log2(块大小)，index 位数 = log2(行数)，tag 位数 = 地址位数 − offset − index。各条件成立时才直接套用。
- 全相联 `--mapping associative` 不设索引，替换策略固定为 **LRU**，命中更新最近访问顺序；不支持其他全相联策略或组相联。
- 全相联 `residentBlocks` 按最久未用到最近使用排列。直接映射槽位下标不代表访问先后。
- 无读写类型、脏位、写策略及访存时间模型，不用于证明相关性能或写回次数。

## 页面置换

- 页号为非负整数，页框数为正；`--initial` 中页不能重复且不能超过页框数，省略则为空。
- 初始列表既是从槽位 0 开始的放置顺序，也是 FIFO 进入顺序或 LRU 从最久未用到最近使用的初始顺序。
- 空槽总选择最小槽位下标；装入空槽只计缺页，不计淘汰。
- FIFO 命中不改变进入顺序；LRU 命中把访问页变为最近使用。淘汰队首页并在其原槽位装入新页。
- `frames` 是固定槽位快照。JSON 没有单独返回 FIFO/LRU 队列；需要该列时标明人工依据规则补出，不称脚本原始返回。
- 只有初始驻留集合而没有先后顺序时，可能不能唯一确定后续淘汰，不随意填 `--initial`。

## CPU 调度

- 输入 `名字:到达时间:执行时间`，名字唯一；到达为非负整数，执行时间为正整数，统一时间单位，无 I/O 阻塞、切换成本或优先级。
- FCFS 非抢占，按 `(到达时间, 名字字符串)` 排序；同到达时不是按输入先后。
- RR 使用正整数时间片，同到达也按名字字符串排序。恰好在时间片末尾到达的进程先入队，再让未完成的当前进程重新入队。
- RR 片内新到者进入就绪队列，但不立即抢占当前进程。输出在到达点分开运行区间，是事件展示，不等于发生额外抢占。
- 空队列时 CPU 空闲到下次到达；进程完成不再重新入队。
- 周转时间 = 完成 − 到达；等待时间 = 周转 − 执行时间。脚本不返回一般意义的首次响应时间，不能把等待时间直接当响应时间。
- 题目规定输入顺序破同到达、边界先重排当前进程或存在切换开销时，不能直接沿用脚本数值。

## 人工计算与调用边界

网络题至少区分 bit 与 byte、十进制链路速率与二进制存储容量、秒与毫秒。传输时延 L/R 和传播时延 d/v 各有不同物理含义；多跳存储转发是否流水重叠须看完整条件，不能一概乘链路数。

脚本仅覆盖 Cache direct/associative、FIFO/LRU、FCFS/RR；网络时延、二分查找、SJF 和其他题型均不在自动支持范围。
用户禁止脚本就不尝试，宿主拒绝时不改名或改解释器绕过；允许人工复核时如实标注。只有实际成功返回的部分才算工具核验，不能用已有安装、历史运行或工程测试代替本题调用。
