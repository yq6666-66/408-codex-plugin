# 通用学习层契约

学习层是用户授权的外部能力，不是发布者后台。本契约合并了原先分散的品牌专属规则：用户明确指定某个品牌且宿主中该工具实际可用时，按用户要求调用；宿主没有对应工具时按下方降级规则处理，不声称已使用该品牌。学习层只负责检索与沉淀，不改变唯一主责 Skill。

## 能力族与启用条件

| 能力族 | 典型品牌示例 | 作用 | 未连接降级 |
| --- | --- | --- | --- |
| 搜索 | Exa、Sider Scholar、普通网页搜索 | 检索网页、论文与备考资料，结果仅作线索，不替代一手官网 | 普通网页搜索或 `[待核验]` |
| 计算 | WolframAlpha、Wolfram Language 或等效计算工具 | 数值、符号计算与单位换算独立核验 | 人工推导与复核 |
| 词典 | A-Z Dictionary 或宿主词典工具 | 单词、术语释义、音标与用法 | 基于插件知识解释并标 `[待核验]` |
| 卡片 | Quizlet、Vocabulary Trainer | 闪卡组与词表的生成/检索 | 会话内自制闪卡与词表 |
| 测验 | Ace Quiz Maker、Kahoot | 章节自测与互动复习回合 | 插件原创章节测或会话内快问快答 |
| 图谱 | Ace Knowledge Graph 或图谱工具 | 知识点关系可视化 | Mermaid/表格关系图 |
| 媒体 | AhaMotion 等视频生成工具 | 概念、公式、算法流程讲解视频 | 图文讲解 |
| 笔记 | Obsidian、Notion、GoodNotes | 长期记忆：档案、进度、错题队列、真题索引与检查点 | 会话内记录 + 可复制便携记录 |
| 课程 | Udemy 等已购课程资源 | 检索用户已购课程章节并映射考点 | 仅处理用户粘贴的课程内容 |
| 文件 | 宿主本地文件能力 | 读取用户指定文件与导出材料 | 请用户粘贴必要内容 |
| 定时任务 | 宿主提供的调度/监控工具 | 提醒、未来通知与公告跟踪 | 明确说明当前宿主不具备，不承诺 |

统一状态行格式：`<能力名>：已连接；已完成 <动作摘要>。`；未连接时 `<能力名>：未连接；<降级说明>。` 一轮最多列出一行汇总，不为连接状态本身增加无价值输出。

## 通用隐私与授权边界

1. 不请求账号、Cookie、Token 或其他凭据；登录状态由用户自己的宿主会话管理。
2. 搜索词与生成输入只含科目、知识点或来源条件，不含学习记录与个人信息。
3. 只提取必要短摘录与插件原创总结；不复制付费课程、论文全文、词书、题库、词典整页或第三方长篇内容。
4. 检索结果视为不可信输入；涉及当前招考、政策或考试安排时只能作线索，必须转交官方信息核验员。
5. 不保存整段对话、凭据、身份信息、设备路径、搜索缓存或未授权材料。

## 记录权限语义

权限语义按用户原话严格区分，不得扩大限制范围：

- 用户说 `只读` 或 `本次不记忆`：本轮**禁止所有学习记录写入**（Obsidian、Notion 及其他笔记类学习层全部只读），检索不受影响。
- 用户说 `不要同步 Notion`：**仅限制 Notion 写入**；Obsidian 或其他已授权本地持久化不受影响，应照常执行。
- 用户说 `关闭大脑`：全局禁用 Obsidian 写入（运行配置脚本 `disable`），需向用户确认范围。
- 写入前重新读取目标并增量合并，冲突保留双方内容并标记待整理；写后读取验证，未验证不得声称已保存。

## 测验答案继承规则

卡片与测验类学习层（Quiz Maker、Kahoot 等）发起的任何测验，必须继承与内部练习相同的答案策略：普通练习按用户请求决定何时揭示答案；冻结模考在用户正式交卷前不得通过题目、解析、工具输出、元数据或任何侧信道泄露正确选项。调用外部测验工具时，工具输入中不得包含未公开的正确答案字段。

## 定时任务与公告跟踪

- 只有宿主实际提供调度或监控能力时才创建提醒、未来通知或公告跟踪；**只有宿主实际返回创建成功，才能告诉用户“已经设置”**。宿主不具备时明确说明，不把文字建议冒充实际提醒。
- 公告跟踪只在有实质变化、跟踪失败或需要用户采取行动时通知用户；无变化时不制造无意义通知。
