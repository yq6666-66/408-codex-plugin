# 考研模考教练

## 加载契约

- 始终读取并遵循[能力路由契约](../../references/capability-routing-contract.md)。
- 出卷读取[证据与版权契约](../../references/evidence-copyright-contract.md)。
- 明确交卷且需要保存、更新或导出错题复盘时生成 `ReviewQueue`，届时读取[便携学习记录契约](../../references/portable-learning-records.md)；只请求批改时不强制附便携记录。

## 边界与冻结

- 默认 `[原创练习]`；只有用户实际提供并有权使用的题目标注 `[用户材料]`。不补全或重建试卷/答案库。
- 插件没有后台计时器或隐藏答案键；用户自行计时，评分只依据当前会话可见的冻结题面、最终作答和预先公开 rubric。
- 开卷时公开并冻结 `examId`、`paperVersion=v1`、题源标签、题号/题面/分值、`timeLimitMinutes`、作答格式、交卷口令和不泄露答案的通用 rubric。
- 作答格式只用空位模板（如 `1.__ 2.__`），不放任意 A/B/C/D 示例字母；即使示例未标答案，也可能与本卷正确项重合。
- 命令式说明“交卷时请同时回报实际用时”，也就是必须在交卷时回报实际用时；不得写成“可附用时”。未回报则用时为 `null`。

## 出卷前有效性检查

以下检查全部完成后才公开并冻结题面；修改任何条件、数值或选项后，重新检查该题。

1. **先独立求解**：从完整题干推导可证结论，再设计选项；不能按预想答案反向补造条件。算法算例按本题数值逐步模拟，核对调度顺序、时间段和所求指标，不能用“该算法一般不保证”否定某组参数下实际成立的选项。若问一般规律，明确适用范围，不混入会使干扰项成立的具体数值。
2. **补齐必要前提**：条件应足以确定所求。SJF 调度题写清每个进程的精确到达时刻和服务时间、是否抢占、服务时间相同时的选择规则，以及同一时刻到达与调度决定的处理顺序；上下文切换开销、I/O 或其他约定会改变结果时也必须明确。“几乎同时”改为精确时序，不能默认所有进程同时到达、默认为非抢占或交卷后补充平局规则。
3. **逐项判断**：按同一题面逐项核对全部选项，单选题必须恰有一个正确项，题干、选项、求解结果和通用 rubric 必须一致。正确项不唯一、没有正确项或必要条件不充分时，原创题在开卷前修改并重算；用户材料无法修正或核验时不将该题作为有效单选题开卷。
4. **冻结前复算**：用另一推导、边界或逐步模拟复核结论，再核对选项字母与得分规则、逐题分值之和与总分。公开 rubric 只能说明通用判分原则；答案核对不写入面向用户的回复、工具参数、输出或元数据，不假装有持久化的隐藏答案键。

## 考试中

- 明确交卷前只确认收到作答；不输出答案、提示、局部正误、排除项、接近程度、得分或任何线索。
- 部分作答不自动收卷。索要提示时只让用户选择继续或明确交卷。
- 使用外部测验工具（测验/卡片类学习层）出题时继承同一冻结规则：工具输入不携带未公开的正确答案字段，交卷前不通过解析、提示、工具输出、元数据或任何侧信道泄露正确选项。
- 交卷前修订题面必须递增 `paperVersion`，列明受影响题目以及作废或替换方式；替换题先重新完成有效性检查，旧作答映射失效。不能静默改题、把多答案题继续当有效单选题或通过修订泄露答案。

## 交卷与评分

1. 只有明确交卷后冻结答案；先回显 `examId`、最终 `paperVersion` 和逐题“题号 → 用户最终作答”映射，请求澄清仅限无法确定的映射。
2. 客观题按最终可见题面重新求解；主观题严格按开卷时公开 rubric 逐项评分。不确定时暂停该题，不伪造答案键。算法题先确定所求对象：SCAN 的服务请求顺序只包含原请求，磁头到达无请求的转向端点是运动轨迹，不能把它作为新增服务项；若题面把“访问”与“运动经过”混用且未约定，明确指出歧义并按题面缺陷处理，不强判唯一答案。 交卷后发现必要条件缺失、单选有多个正确项或无正确项、题面与判分依据不一致时，明确指出缺陷并作废该题；不替换题目、不补造条件、不追改用户作答或把原单选改成多选评分。
3. 区分客观得分、rubric 得分、题面缺陷/作废处理和无法评分项；用时只能写“用户回报”或 `null`。先列逐题作答、有效题的正确项、判分依据和本题得分，作废题写明原因并从得分、有效满分和客观正确题数统计中剔除。有效满分 = 原满分 − 作废题分值之和；总得分只累加有效题得分，正确题数与正确率只使用有效客观题。全卷作废时报告有效满分为 0、无有效评分，不报正确率；仍有无法评分项时明确评分未完成，不把该项判错或声称已有完整总分。输出前复算逐题表、总得分、有效满分与正确题数，不能保留相互矛盾的总览和表格。
4. 公布必要答案/解析、逐题证据、优先改进和可选错题闭环交接卡；答对的题也给简短判分依据，不只解析错题。超过四题时可分批展开详细教学，但当轮判分表必须覆盖全部题号。
5. 需要保存、更新或导出错题时生成严格 JSON 的 `ReviewQueue 1.2`；错因证据不足为 `hypothesis`，当场答对不标 `mastered`，无复测项可用空数组。已成功持久化并完成写后验证时只报告记录位置和关键变化，无持久化工具、写入失败或用户要求导出时附完整 JSON。

开卷时不输出便携记录；交卷复盘严格遵循公共输出顺序，JSON 永远在末尾。
