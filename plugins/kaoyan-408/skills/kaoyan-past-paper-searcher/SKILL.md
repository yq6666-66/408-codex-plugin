# 考研真题搜索器

## 加载契约

- 始终读取 [能力路由契约](../../references/capability-routing-contract.md)。
- 必须读取 [真题来源与入库契约](../../references/past-paper-source-contract.md) 和 [证据与版权契约](../../references/evidence-copyright-contract.md)。
- 生成记录时按 [真题知识 Schema](../../references/past-paper-knowledge.schema.json) 校验。

## 工作流

1. 规范化科目、`paperYear`、实际考试年份/日期、试卷类型和用户需要的内容。科目范围是数学一、数学二、英语一、英语二、408、政治六类；检索起点 2010，不设结束年份上限：未来年份按真实可访问来源判断是否已公开，不因超过固定年份而判定不存在。若官方尚未公布具体考试日，输出 `examDate: null`、`examDateStatus: 未公布/待官方公告` 和有依据的时间窗口。超出六类的请求说明固定边界。
   日期与时段分别核验：将当年官方初试安排与该科目在招生目录中的单元、分值和排序对应后，才填写上午/下午。数学二的“二”是卷型，不是“业务课二”；四单元的 150 分 408 不能因名称含“专业基础”就等同三单元的 300 分专业基础综合。仅查到全国考试日期、未证实具体科目时段时，只给有依据的日期，把时段留作 `[待核验]`，不凭名称或惯例补齐。
2. 检查宿主是否提供网页搜索。可用时分别执行普通网页与 `site:github.com` 精确查询；不可用时输出 `[真题未命中]`、搜索式和手动核验步骤。
3. 打开候选原始页面，不以摘要作证。所有科目先从实际打开正文中读到题号、题干与决定答案的要素；不同搜索摘要一致也不能算交叉核验。英语、政治及非公式 408 题按科目核对关键句、可见选项、给定数值或操作顺序，不套用数学公式模板。对公式题按下列专属步骤复核。GitHub 候选检查仓库、文件路径、commit、raw URL、LICENSE 及其覆盖范围。
   数学公式题若 PDF 打开结果为 0 行、只有标题或页数，即使摘要显示公式，也未取得可核对题面，不能宣称原卷或题目已核验。PDF 抽取若把指数、分式、上下标或顺序拆乱，核对清晰原页图像或另一份实际打开且公式完整可读的原始题面；不能从答案反推公式。
   **仅对数学公式题适用**：先逐项抄写外层倍数、括号内增量、分母和指数，并在原页逐个核对；清晰原页或实际打开、公式完整可读的第二来源须直接支撑这些字段。搜索摘要、答案相同和同一 PDF/OCR 的转述都不算交叉核验。任何一项看不清或两个来源不一致，标 `[待核验]`；若用户当前已提供足以求解的题面，可按该用户题面继续讲解，但来源身份仍待核，不能称为已核验原卷。没有可用用户题面时，仅按用户意图明确改用数学 `[原创示例]`。讲解前按模板给出“题面核对：外层倍数=<...>；括号内增量=<...>；分母=<...>；指数=<...>”，每个字段须由本轮实际可读的用户题面、工具正文或清晰图像直接支持；用户题面只支持其实际内容，不证明来源。只有认定为已核验原卷时，数学公式题的工具输出中必须实际显示完整公式文本，或显示清楚的原页图像；仅有打开状态、页数或 `Total lines` 等行数仍视为没有读到可核验公式。
   英语、政治和非公式 408 题须实际读到来源正文中的题号、题干关键句、选项（只使用可见选项）及会决定答案的数值/顺序。公式槽位确实与题型无关时写 `不涉及`；若题目依赖公式或其他关键要素而来源未显示，则是缺失证据，不得写 `不涉及`。有可用的直接正文读取工具时先获取网页正文，确认该题适用的关键要素实际出现在工具输出中；所有科目都不能只凭标题、页数、成功打开状态或搜索摘要称为已核验题面。
4. 用户在同一条请求中要求“找来源后直接讲题”时，搜索器负责发现来源并核验可读题面；主 Agent 在本轮把已核验的题面证据继续交给对应的数学、英语、408 或政治教练，读取其 Skill 与教学契约并连续调用完成讲解。不得只附交接卡或要求用户再次提交题目。只把工具正文、可读图像或用户本轮实际提供且可读的题面支持的内容交给教练；来源不可核验时，用户题面标为 `[用户材料]`，来源标 `[待核验]`，不得声称已核验原题。若没有足够可读题面，不得交接假题。先在引用边界内列出足够独立求解的原题条件与所求，再补必要概念、展开关键推导；含选项时逐项说明所有可读选项，最后给另一方法、反例或边界检查作为独立复核。来源摘要不能代替这段教学，不能只报选项或几个结论。用户已在会话中提供题面且未要求核验出处时，不启动真题搜索；按当前主要目的由对应学科教练或 408 专用入口处理。
   用户主要要求查来源，同时只要求对已读到的 408 题面定位单题首错、解释局部概念或明确验算时，主 Agent 在核验题面后可按当前目的串联对应专用入口；仍须保持本轮权限和提示边界，关键题面不可读时不得交接假题。
5. 比较年度、科目、题号/页码、版式、完整度和 SHA-256；建立来源冲突与重复项表。
6. 为每个合格候选输出 `PastPaperSource`。许可证明确允许时可建议 `full-text`，否则固定 `index-only`。
7. Notion 绑定或启用 Obsidian 只用于定位目标，不代表本轮写入授权。用户本轮明确要求保存或已有覆盖本内容的有效持续授权时，才按记录契约写入来源索引和许可允许的内容；全部只读时不得向任何笔记层写入，仅禁止 Notion 时仍可按授权使用其他可用笔记层。未确认真实性或许可时不得自动保存全文；写入后须读回验证，失败不得称已保存。
8. 政治试卷答案涉及当年时政时，按该试卷实际适用的考试年度核验当年时政语境，不得用当前年份新闻替代历史年度表述。

## 输出

取得可核对的原卷题面时用 `[真题证据]` 给最可信来源，并列出实际打开后读到的题号、题干关键处、来源链接，以及 `paperYear`、`examDate`/`null`、日期状态、候选来源表、许可/真实性判断、冲突与缺口、可保存范围。若不能从工具返回的正文或图像列出完整题面证据，就用 `[待核验]` 说明候选链接与未读到的部分；需要讲题时，用户当前已提供足够题面则按 `[用户材料]` 继续处理并保留出处待核；没有可用用户题面时，仅按用户意图改用明确标注的原创示例。不能把搜索摘要中的式子或用户标称来源称为已核验卷中题。同一请求还要求讲题时，主 Agent 在本轮按主要目的串联对应学科教练或 408 专用入口，传递已核验的来源题面，或用户已提供且可求解的题面及其待核出处状态；不得只附交接卡或要求用户重发题面。用户已提供题面且未要求来源核验时直接处理，不经过搜索器。提交讲解前逐项核对正文是否包含：原题已知与所求、必要前置定义及方法条件、关键推导、各可读选项的判断理由、另一方法的具体复核计算与结果。缺项先补齐，不能用来源摘要、答案字母或同一差商的再次换元代替教学；只有用户明确简洁覆盖时才压缩。确有后续分析需要时才附交接卡给 `$kaoyan-past-paper-analyst`。不得把候选链接描述为已下载、已核验或已入库。
