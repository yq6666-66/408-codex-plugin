# 每题依据的四个部分

本文件适用于三个 408 场景。它把实际解题规则、规则的来源、年度大纲归属和题面来源分开，避免一个“已核”标签替代所有证明。

## 1. 实际规则和适用条件

说明本题实际使用的定义、公式或状态更新规则，并列出会改变结论的条件。计算题还要说明单位、初态和算法约定。相同知识点可能使用不同公式或处理不同条件，知识点 ID 不能代替规则。

[rule-cards.json](rule-cards.json) 是项目原创规则归纳，仅可在条件吻合时引用。卡片的 `source.kind` 始终为 `project-summary`，不能称教材、大纲或标准原文。`project-reviewed-external-pending` 表示外部出处待核；`project-reviewed-external-partial` 表示另列的 `externalReferences` 已实际阅读并支持其中明确列出的部分规则，不表示整张卡及全部模拟器约定均获来源证明。

当前八张卡均有部分外部支持。使用时同时读取引用中的 `supports` 与 `limitations`，给实际来源标题、定位和核验日期；同到达名字排序、RR 片末事件顺序、固定页框槽位或无切换成本等项目约定不能借来源的权威性升级为通用规则。来源条目的 `verification: verified` 仅对应所列支持范围，不改变年度大纲映射状态，也不证明用户答案正确。

没有对应卡片时可给出有条件的人工推导，并明确“外部依据待核验”。不要为了有引用而套用不匹配的卡片。用户已实际提供并读到的规则材料可标“用户材料”，只给可见定位；额外外部核对只覆盖本轮实际读过的内容。

## 2. 知识点和年度大纲归属

在 [kp-408.json](kp-408.json) 中按题面匹配条目。`id` 是项目内部 ID，`topicPath` 是项目分类，不是官方编号或年度路径。别名仅供检索，不能凭字面直接判断；普通 FIFO 队列不能自动匹配为 FIFO 页面置换。

索引有 60 条，四科各 15 条，是编辑优先级，不是命题频率统计。17 条映射核对到芜湖学院计算科学学院公开的 **2025 年学校材料**，43 条年度归属待核；**2027 年全部仍待核**。不由目标考试年、网页标题或模型记忆默默升级。

- `verified: true` 仅证明与所列年度和来源正文的映射已经核对，不证明定义、公式、答案或用户错因正确。
- `mappingScope: topic` 证明主题归属，不保证所有项目别名在原文逐字出现。
- `mappingScope: upper-topic` 仅证明上位主题范围。Cache 字段划分等细节是项目展开，不称大纲逐字公式。
- `source.kind: official-repost` 保留实际学校发布者，不能改称考试主管部门或出版社原始发布。
- 来源的 PDF 页码是该 PDF 的定位，不是教材页码。

显示实际 `basisYear`、`source.title/publisher/reference/locator` 及其范围；待核条目保留待核状态。目标年度不同时明确两者差异，未指定目标年度也不能省略为“当前大纲已核”。

无法可靠匹配或索引未收录时使用 `pointId: null`，保留真实知识点名称、规则及条件，并写“未收录/年度归属待核”。不要制造 ID、章节、页码或来源 URL。

## 3. 题面与参考答案来源

用户在当前会话提供的题面写“用户题面”；自编示例、迁移题或验证题写“原创示例/原创练习”。用户称其为某年真题但没有核对原始出处时，只记为“用户标称，题面出处未独立核验”。参考答案单独标明来源；其存在不能证明使用的规则或教材出处已核。

## 4. 复核方式与输出

默认每题用一至两句表达，不强制输出 JSON：

> 【知识点依据】项目 ID/未收录；实际规则与关键条件；规则来源及外部核对状态；年度大纲映射的实际年份、状态与定位。题面来源另记；计算结果注明脚本核验/人工复核/条件不足。

需要结构化导出时，规则部分使用 `pointId`、`pointName`、`rule`、`conditions`、`source.kind/title/locator/verification`；年度归属放独立的 `syllabusMapping`，题面放 `problemProvenance`，不要把卡片来源和学校大纲来源混成一个字段。

只在真实调用成功且返回对应本题时称“脚本核验”；人工推导就写“人工复核”。学习错因的观察与假设分开，来源已核不能把假设升级为用户确实犯错。

用户只要提示或保留答案时，防泄题优先于完整格式。精确知识点、卡片名、ID、公式或定位会暴露方法时，先写宽泛主题与“详细依据留到讲评”，获得讲评请求后再补齐。
