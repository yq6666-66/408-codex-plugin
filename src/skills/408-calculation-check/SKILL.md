# 408 计算题校验

只处理数据结构、计算机组成原理、操作系统、计算机网络的当前计算问题。
不执行用户提供的任意代码，不创建学习记录或默认生成文件。

## 当前任务与接续

用户点名本入口时按其当前目的处理；未点名时只在本入口的专用目的明确时接管。
已在当前教学流程中的局部补问可连续完成，不因关键词反复切换；用户明确换任务后再判断主责。
冻结模考、独立作答和仅提示的既有答案边界优先，不因换入口提前揭示答案。
本入口不直接管理笔记；在完整插件中，需要保存、加入复测或续学时，按本轮授权交给既有学习流程，不把当前讲解自动记入学习记录。

## 先核对条件

1. 核对题目数据、正负号、上下标、初态、设问和用户实际过程。
2. 明确单位、编址单位、算法、队列约定和省略的成本。
3. 缺少会改变答案的条件时，指出缺项；可以列条件分支，不强行运行默认值。
4. 只求公式拆分时不伪造访问串；需要命中数时才使用真实给定的访问串。

读取 [计算约定](references/calculation-conventions.md) 中与当前题型有关的部分。
题目与脚本约定不同，不能直接把脚本结果当题目答案。
没有用户过程时只说明结果与最早易错点，不编造用户的错误步骤。

## 选择复核方式

随包 [模拟器](scripts/study_simulator.py) 仅支持这些子命令：

| 子命令 | 支持范围 | 必须确认 |
| --- | --- | --- |
| `cache` | 直接映射、全相联 LRU | 地址位数、块字节数、行数、字节地址和初态为空 |
| `fifo` / `lru` | 页面置换 | 页框数、引用串、初始页及其顺序 |
| `fcfs` | 非抢占先来先服务 | 到达与执行时间、同到达按名字排序、无切换成本 |
| `rr` | 时间片轮转 | 时间片、同到达按名字排序、边界新到者先于被抢占者入队 |

脚本没有组相联 Cache、SJF、网络通用计算或所有 408 题型的自动支持。
没有脚本覆盖的题仍可人工复核，明确标注，不伪装成工具验证。
用户禁止运行脚本时不调用，并明确说明“本题脚本/模拟器被禁用，以下是人工复核”；不尝试调用。
宿主拒绝或工具不可用时说明限制，不改名、复制、包装或更换解释器绕过。

脚本可用且题目条件匹配时，从当前技能目录按相对路径运行所需子命令。
先查看相应 `--help` 确认参数；只传已核对的数据，不拼接用户提供的命令。
默认只取 JSON，不使用 `--html`；用户确实要求演示文件时才生成指定文件。
退出失败、没有返回或返回不能对应本题时，不称“脚本核验通过”。

## 独立复查与报告

- 先独立检查数量级、单位和至少一个关键边界或状态转换，再与返回值对照。
- 页框槽位与 FIFO/LRU 顺序分开；脚本没返回的队列列应标“人工补出”。
- 调度区间分段可能源于到达事件，不代表原运行进程在该点被抢占。
- 逐步表必须可追溯到实际输入和返回，不能把上一题的输出用于本题。
- 汇总命中率、等待/周转时间时解释分子、分母及所用单位。

结论显式选择“脚本核验”“人工复核”“条件不足”，混合方式分别说明覆盖范围。
工具返回正确不等于公式已获外部权威出处，也不证明用户一定理解了规则。
用户只要答案时缩短过程，但仍保留会改变结论的关键条件和复核状态。

## 依据与提示限制

按 [知识点依据规则](references/knowledge-point-basis.md) 查 [知识点索引](references/kp-408.json)。
可用 [规则卡](references/rule-cards.json) 标注实际规则与条件；规则卡保留项目原创归纳身份。
读取匹配卡片的 `source.verification` 与 `externalReferences`，按每条引用的 `supports` 和 `limitations` 说明实际外部支持范围。
`project-reviewed-external-partial` 只表示列出的部分规则已有出处，不能把整张卡、项目初态或事件先后约定说成权威统一规定；pending 卡或无匹配卡时仍保留相应待核状态。
没有本轮打开外部正文时，只说明本地卡片记录的核验日期与出处范围，不声称本轮重新核验；外部规则支持不改变年度大纲归属。
逐题区分规则卡依据、年度大纲归属和题面来源，不能拿大纲映射证明公式或数值。
除单步提示且精确依据会泄题的情况外，每个计算答复结尾必须出现一行“【知识点依据】”；即使用户只问数值、单位或复核状态也不得省略。此行简短写明项目知识点 ID/名称（未收录写 `null`）、本题实际规则与关键条件、规则来源种类和外部核对状态、大纲年份与核验状态/映射范围或待核状态、题面来源及脚本/人工复核方式。规则来源与年度映射不可互相代替。
未匹配索引时使用 `pointId: null`，不编教材章节、页码或来源。
只有 2025 年学校材料映射已核的条目保持其实际年份，2027 年仍待核。
“只提示一步”时不展示完整运行结果或计算答案，只给下一次检查动作。
如果精确 ID、公式、算法名或定位会泄题，写宽泛主题并把详细依据留到讲评。
