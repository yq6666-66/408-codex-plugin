# 完整插件与新增技能的兼容使用

2026-10-24 用户明确：主线是优化旧技能、增加新技能，而不是删除。完整 `kaoyan-408` 插件已恢复为当前维护基础。此前切换至三场景的操作曾实际发生，现通过新增提交恢复，不重写历史；原切换报告仅为历史记录。

## 保留的完整能力

`plugins/kaoyan-408` 保留 14 个技能、共享契约和 4 个运行脚本。跨科规划、数学/英语/政治/408 辅导、招生与真题检索、材料学习、模考、执行与进度、错题复测、检查点和可选 Obsidian/Notion 学习记录继续维护。14 是当前基础，不是新增入口的上限。

完整插件版本仍由 `.codex-plugin/plugin.json` 定义，清单由既有同步工具派生；现为 `2.8.0-dev.1` 未发布开发候选。此前 `2.6.1` 发布候选继续保留，正式标签与 Release 仍须确认。

## 新增场景如何接入

三个独立候选 `408-error-diagnosis`、`408-concept-followup`、`408-calculation-check` 和源码/工具继续保留，目前尚未加入主插件清单。可以按需独立装配试用，之后依据用户需求与路由验证决定作为新增入口接入，或将有效规则接回现有 tutor/错题闭环；不能借此移除旧能力。

`skillset.json` 仅定义独立三场景分发，与完整插件版本分开。试用时只在隔离项目安装所需技能；原始 `src/skills` 需要装配，不能直接作为安装副本。能力重叠时明确实际调用入口，避免把显式调用测试当作自动路由通过。

## 学习记录与安装保护

保留 `StudyProfile`、`ProgressSnapshot`、`ReviewQueue`、`SessionCheckpoint` 及现有 1.0/1.1 输入兼容和 1.2 记录约束。后续优化不能丢弃历史记录或冲突项；检查点修订号仍按契约判断。Obsidian/Notion 的权限、写入后读回和数据校验规则继续生效。

本次恢复不操作用户安装、配置、缓存或真实笔记。持久记录能力保留不代表已完成真实笔记写入验收；新客户端材料与 Codex CLI 文件读取按此前用户要求跳过，状态仍为未验证。不得以改写记录或关闭守卫伪造通过。
