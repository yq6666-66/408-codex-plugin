## 功能

完整插件在原 14 个技能基础上增加 408 单题错题归因、概念追问和计算题校验三个入口。原有跨科规划、数学、英语、政治、408、真题与招生检索、模考、学习执行、进度诊断、错题复测及持久学习记录继续保留。

新增知识点依据和项目规则卡；项目归纳、外部来源支持范围和年度大纲映射分别表达。2025 年材料的映射不能替代 2027 年度核验，缺失资料仍标待核。记录 Schema 1.2 保持对 1.0 和 1.1 的读取兼容。

## 安装与恢复

发布完成后从正式 Release 下载插件 ZIP 和校验文件，或按 [安装指南](installation.md)使用固定标签。回退或迁移之前先备份学习记录；用户的既有安装和笔记不会因仓库发布自动迁移。
