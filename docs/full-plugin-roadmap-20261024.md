# kaoyan-408 完整功能增量优化计划

更新：2026-10-24。用户最新要求是“主线是优化旧技能增加新技能，而不是删除”。本文件作为当前执行方向，取代此前将主线缩减为三场景的目标；原提交、计划和验收记录保留历史含义。

## 产品目标

以完整考研学习插件为基础，持续优化现有技能并按实际需要新增技能。覆盖数学一/二、英语一/二、408 与政治，以及跨科规划、执行与进度、真题与招生研究、材料学习、错题复测和学习记录。14 是当前已有入口数，不是数量上限。

功能是否保留由用户需求和明确的变更决定，不能以“同名”“重叠”“只保留高频”或“统一格式”为由删除。同一份来源明确的实现和资源可以被多个入口复用，维护去重不等于删除用户能力。
