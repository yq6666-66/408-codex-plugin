# 408-agent-skills 3.0 开发候选实施

依据：既有三场景设计及用户 2026-10-19“跳过新客户端验收材料，Codex CLI 文件读取”的指令。两项从本次前置门禁移除，状态保留 skipped-by-user；不把 2.8 自动路由或真实客户端结果补成通过。旧入口的删除、归档、用户安装变更和发布批准边界不变。

## 交付和检查

1. `src/skills` 只维护三个场景正文，`src/shared` 维护共同知识规则和计算实现；`skillset.json` 是 3.x 唯一版本和装配依赖来源。旧 2.x 目录原位保留，独立版本与发布记录不改写。
2. `tools/skills.py` 导出 Claude/Codex/Cursor 本地 Skills 布局，各自资源自包含，带 MIT 许可；三个平台共用同一正文和资源，不增加宿主权限/后台服务。
3. 统一工具只在明确目标下安装；验证独立技能、幂等、冲突、备份、失败恢复、越界/链接拒绝。同内容来源不明时只复用，不冒认为可管理。
4. 知识点保留 60 条及原核验范围，新增约 8 张项目原创规则卡，规则条件与脚本/年度大纲分离。检查独立数值结果，不通过来源标签代替解题正确性。
5. 三端 ZIP 使用固定排序、时间和权限；Windows/Ubuntu 原始字节比较。新增独立 Skills CI，不改旧插件 Release 流程，不自动发版。
6. 采用可用的 app 定向模型环境抽查三场景及边界，绑定新装配树、记录公开工具和回答、独立评分。显式读取不同于原生自动发现；跳过的客户端和 CLI 项目仍不作支持结论。
7. 新 README 优先介绍三场景和统一入口，旧 14 入口映射、兼容及回退另列 [迁移说明](../../v3-migration.md)。候选工程与行为记录放 `eval/v3.0-acceptance`，产物放忽略的 `dist`。

当前开始于 `3c0b292`，分支 `codex/v300-three-scenes`；实际完成情况和产物摘要另写验收记录，不在此预填通过。GitHub 仓库地址保留，版本标签和 Release 均不在此实施授权内。
